# CODE: OVERWRITE - project Ren'Py 8.x (lengkap)

## Cara buka
1. Ekstrak zip. Hasilnya folder `CODE_OVERWRITE` yang berisi `game/`.
2. Buka Ren'Py Launcher -> Preferences -> Projects Directory. Pindahkan folder `CODE_OVERWRITE`
   ke dalam folder projects itu (atau ubah Projects Directory ke folder tempat `CODE_OVERWRITE` berada).
3. Klik Refresh di Launcher, pilih `CODE_OVERWRITE`, lalu Launch Project.

## Isi
game/
  options.rpy  gui.rpy  screens.rpy      (dasar project)
  cod_core.rpy cod_effects.rpy cod_menu.rpy cod_meta.rpy cod_minigames.rpy
  script.rpy                              (cerita Act 1-4)
  images/  audio/  fonts/                 (isi sendiri, lihat README di tiap folder)

Folder game/characters/ dibuat otomatis oleh gim saat dijalankan. tolong jangan taruh file lain di sana.
